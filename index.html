Quick Start

四步跑起来

有 Docker 就能装，无需编译。

获取配置

克隆仓库并准备环境变量。

# 克隆 git clone https://github.com/DC1024/iso-hub # 准备 .env cp .env.example .env

配置端口与路径

编辑 .env，设置 Web 端口、SMB / WebDAV 端口及数据挂载目录。

# .env 关键项 WEB_PORT=8080 SMB_PORT=445 WEBDAV_PORT=8081 DATA_DIR=/mnt/iso

启动

一条命令拉起三容器。

# 启动全部服务 docker compose up -d

打开网页

浏览器访问 http://<你的IP>:8080，登录后开始追 ISO。

# 默认访问地址 http://localhost:8080
# 一行部署（示意） git clone https://github.com/DC1024/iso-hub && cd iso-hub && cp .env.example .env && docker compose up -d
FAQ

常见问题

ISO Hub 和 iso_download 是什么关系？

ISO Hub 是 Sowevo/iso_download 命令行工具的网页封装：把原本在终端里执行的「查元数据 / 选版本 / 下载 / 校验」搬到了浏览器，并补上了 SMB / WebDAV 共享。

需要自己编译吗？

不需要。官方以 Docker 镜像分发，docker compose up -d 即可运行，全程无需本地编译。

元数据从哪来？国内访问快吗？

默认基于清华镜像站(TUNA)的元数据，国内访问延迟低、更新及时；也可切换到中科大等其它源，或接入自定义镜像源。

下载的 ISO 怎么取用？

落盘后通过内置的 SMB（局域网共享）与 WebDAV（可挂载为网盘）直接分发，跨平台都能访问。

支持哪些发行版？

覆盖 Ubuntu / Debian / Arch / Rocky / Alma / Fedora / openSUSE / CentOS / Kali 等主流发行版，并持续扩充。
