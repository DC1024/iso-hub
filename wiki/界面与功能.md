# 界面与功能总览

本篇逐个页签讲清"这个页面上有什么、点了会发生什么"。想先知道整体定位和架构，
看 [项目概览](项目概览)；想查接口细节，看 [API 一览](API)。

顶部导航共 5 个页签：**📦 镜像列表 / 🔗 自定义源 / ⭐ 订阅同步 / 🧲 种子下载 / ⚙️ 设置**
（1.0.3 起「网络共享」并入「设置 → 共享设置」；🧲 种子下载为 1.3.x 起新增）。

## 顶部栏（所有页面可见）

| 元素 | 作用 |
|---|---|
| 标题徽章（如 `1.8.3`） | 版本号。**以 `/api/health` 返回的 `version` 为准**，HTML 里写死的常量只用于首屏兜底 |
| 🏠 首页 / 镜像 | 回到镜像列表 |
| 🔄 刷新列表 | 重新从后端加载当前清单（**不**抓镜像站，只重读本地元数据） |
| 🔗 自定义源 | 切到自定义源页 |
| 🧲 种子下载 | 切到种子下载页 |
| ⭐ 订阅同步 | 切到订阅页 |
| ⚙️ 设置 | 用户 / 语言 / 源策略 / 存放模式 / 邮件 / 共享 / qB / 定时任务 / 受保护列表 |
| ⬇ 下载到本机 | 把**当前面板勾选**的已完成文件拉到本机浏览器（镜像列表 → 发行版文件；种子页 → 勾选种子里已完成的文件） |
| ⬇ 下载所选 | 让**服务器**下载勾选的版本（与上一条不同：一个是下发到服务器，一个是拉回本机） |
| ■ 停止任务 | 停止当前下载 / 刷新任务 |
| 🌓 | 日夜主题切换 |

> **「刷新列表」≠「抓取最新版本元数据」** —— 这是最容易混的一对：
> - **刷新列表**：只重读本地 `distributions.json` 到界面，**不联网**。用于后台任务完成后刷新展示。
> - **抓取最新版本元数据**：联网访问镜像站目录，把**最新版本**写进 `distributions.json`
>   （默认每组保留最新 3 个），然后刷新列表。

### 哪个页签 / 哪个筛选，刷新后还在

以下状态都会持久化，刷新页面不会回到默认值：

| 状态 | 存储位置 | 说明 |
|---|---|---|
| 当前页签 | 浏览器 `localStorage` | 非法值收敛回「镜像列表」 |
| 镜像列表筛选 | 浏览器 `localStorage` | 失效值收敛回「全部」 |
| 折叠状态 | 浏览器 `localStorage` | 折叠键由后端下发，切语言/计数变化不会丢 |
| 勾选集合 | 内存 + 重绘回填 | 以 `download_url` 为键，跨筛选、跨重绘保留 |

> 勾选能跨筛选保留之后，"看不见的行会不会被顺手删掉"就成了必须显式保证的事 ——
> 所以删除/下载这类动作**只对当前可见的勾选行生效**（区别于"按集合全删"）。

## 📦 镜像列表页

### 统计条

发行版组数 / 清单文件数 / 本地已占空间 / 元数据更新时间。

### 筛选（6 项）

全部 / 已下载 / 未下载 / **下载中** / **下载失败·停止** / 已收藏。

### 表格结构（8 列）

| 列 | 内容 |
|---|---|
| ☑ | 勾选框（分组头带半选态全选框） |
| ★ | 收藏 |
| 文件 | 文件名（含版本、架构、变体） |
| 本地大小 | 磁盘上实际占用；未下载为空 |
| 镜像源 | 该行用哪个源下载。默认「自动」，也可手动指定某个源 |
| 状态 | 五态徽标，见下 |
| 锁定 | 🔒 受保护开关 |
| 操作 | 行内 ⬇ 下载到本机 / 🗑 删除 |

### 状态五态

| 徽标 | 含义 | 怎么产生的 |
|---|---|---|
| 下载中 | 有活跃任务正在写这个文件 | 运行中任务上报的活跃 `.part` 路径命中 |
| 已下载 | 完整文件存在，且校验通过 | 最终文件名存在 |
| 下载停止 | 半成品（可续传） | 磁盘上残留 `.part`，且无活跃任务 |
| 下载失败 | 需要重下 | 失败记录里标记为需重下 |
| 未下载 | 本地没有 | 以上都不命中 |

> 「下载中」和「下载停止」在磁盘上都表现为一个 `.part`，区别只在于**有没有任务在写它**。
> 这也是为什么状态判定不能只看文件系统。

### 行内操作

- **⬇ 下载到本机**：只有完整文件才有（由后端下发的 `downloadable` 决定，不靠前端猜）。
- **🗑 删除**：完整文件、`.part` 半成品、下载失败的行都能删。
- **🔒 锁定**：锁定后清理过期、订阅同步、手动删除全部**硬拒绝**（没有 `force` 绕过参数）。

### 底部 / 工具条操作

下载所选 · 停止任务 · 删除所选 · 清理过期（列出不在最新清单里的旧文件）· 抓取最新版本元数据。

## 🔗 自定义源页

添加清单里没有的发行版或任意 ISO 直链（Kali、特定 LTS、内网自建源）。
独立保存到 `custom_sources.json`，**不会被元数据刷新覆盖**。

支持两种条目：

- **普通直链**：发行版名 + ISO 直链，添加后立即合入镜像列表。
- **发行版源（strategy 目录抓取）**：`listing_url` + strategy，需先「🔄 刷新发行版源」
  展开为具体 ISO 条目。

页面操作：

- **🔄 刷新发行版源**（`POST /api/custom-sources/refresh`）：后台子进程重新展开所有 strategy 源并写缓存。
  请求线程只读缓存、不联网，所以不会卡页面。
- **自动定时刷新开关**（`GET/POST /api/custom-sources/auto-refresh`）：可开关并设间隔（秒）。
  **默认关闭**，间隔默认 `86400`（每天），最小 `60`。

> v1.1.6 起 strategy 源的展开改为"持久化缓存 + 后台子进程"。此前在请求线程内直接抓站，
> 一个慢站就能占满 waitress 线程池，把全站拖死。

详见 [自定义源](自定义源)。

## ⭐ 订阅同步页

为每个发行版开启订阅，并设保留版本数 N。每次同步执行：

```text
刷元数据 → 下载最新 N 版 → 删除超出 N 的旧版（🔒 锁定跳过）
```

可以「立即执行」，也可以交给内置调度器（`ISO_HUB_SYNC_INTERVAL`，默认 86400 秒；
设 `0` 关闭）或网页上自建的定时任务。详见 [订阅同步](订阅同步)。

## 🧲 种子下载页

三个子标签：

| 子标签 | 内容 |
|---|---|
| 📚 种子源 | DistroWatch 官方列表（按分类折叠）/ 手动粘磁力链接 / 自建 RSS 源；搜索框实时过滤 |
| ⏳ 下载列表 | 进度、**全部 / 下载中 / 已完成 / 做种**筛选、删除、勾选后拉到本机 |
| 🏷️ 分类管理 | 6 个预置分类（只能禁用不能删）+ 自定义分类（最多 50 个，关键词/排除词各 50 条） |

匹配语义刻意区分：**关键词按词首**匹配（填 `ubuntu` 覆盖 `ubuntukylin`），
**排除词按完整词**匹配（`arch` 不会误伤 `search`）。未命中任何分类的进「未分类」并固定排最后。

支持内置 qBittorrent sidecar（需 `--profile bt`），也支持填**外部** qB 实例的地址 ——
后者只走 Web API 登录，不碰任何容器。详见 [种子下载](种子下载)。

## ⚙️ 设置页

按卡片从上到下：

| 卡片 | 能做什么 |
|---|---|
| 👤 用户设置 | 登录 / 修改管理员密码（PBKDF2-SHA256） |
| 🌐 语言设置 | 中文 / English / 自动（跟随浏览器） |
| 🌐 镜像源策略 | **A · 固定优先级** / **B · 实测选最快**；对应 `ISO_HUB_SOURCE_STRATEGY` |
| 💾 存放模式 | `classified`（按类型/发行版分目录）/ `flat`（全部平铺到 `iso/`）。**只影响之后的下载，已下载文件不搬迁** |
| 📧 邮件通知 | 下载任务结束时发结果邮件（含成功/失败清单）；端口默认 465/SSL，支持无加密与 STARTTLS；密码不回传前端 |
| 🔗 共享设置 | SMB / WebDAV 开关与凭据；显示动态端口地址。凭据以**明文**存在 `settings.json`，页面上有明确提示 |
| 🧲 qBittorrent | 内置 sidecar 或外部实例地址、用户名、密码；外部实例可填地址直接连接 |
| ⏰ 定时任务 | 每天 / 每周 / 每月 / 每年 / 一次性；`type` 走白名单、`time` 走 `HH:MM` 校验，非法入参**一律 400 且不落盘** |
| 🛡️ 受保护列表 | 被 🔒 锁定的文件（清理 / 订阅同步跳过），可批量管理 |

> **共享密码没有默认值。** 从 1.3.21 起取消了内置的 `iso123` —— 密码为空时直接拒绝启用共享，
> 避免"部署完就有一个公开可读的共享"。

## 任务进度与日志

- 顶部任务条：任务类型（下载 / 刷元数据）、标题、**进度条 + 百分比**、当前文件、已下载大小与速率。
- 下方日志面板实时滚动（下载每文件、校验、清理等事件）。
- 前端 **5 秒轮询** `/api/state`；任务运行期间列表也会刷新，中途就能看到状态变化。

进度条的口径值得说明：**已完成文件从分子分母一起剔除**，只统计"本轮还有活要干"的文件 ——
否则一次订阅同步会先被已完成的大文件垫到 50%，之后真正在下的文件再涨也推不动指针。

> 进度条卡 0% / 日志只在停止后才刷出？那是 1.0.2 修掉的变量遮蔽问题，
> 见 [常见问题](常见问题-FAQ) 的「进度条卡 0%」条目。若仍复现，先确认徽章版本号。
