# 界面与功能总览

顶部导航：**镜像列表 / 🧲 种子下载 / 自定义源 / ⭐ 订阅同步 / ⚙️ 设置**（1.0.3 起「网络共享」已并入「设置 → 共享设置」；🧲 种子下载为 v1.3.x 新增，详见 [种子下载](种子下载)）。

## 顶部栏（所有页面可见）

| 元素 | 作用 |
|---|---|
| 标题徽章（如 `1.0.6`） | 前端版本号，用于核对是否最新 |
| 🏠 首页/镜像 | 回到镜像列表 |
| 🔄 刷新列表 | 重新从后端加载当前清单（**不**抓镜像站，只是重读本地元数据） |
| 🔗 自定义源 | 切换到自定义源页 |
| 🧲 种子下载 | 切换到种子下载页（qBittorrent / 下载到本机，详见 [种子下载](种子下载)） |
| ⭐ 订阅同步 | 切换到订阅页 |
| ⚙️ 设置 | 用户/语言/共享/定时任务/受保护列表 |
| ⬇ 下载到本机 | 把**当前面板勾选**的已完成文件拉到本机浏览器（镜像列表→发行版文件；种子页→勾选种子里已完成的文件；v1.3.18 起两面板合并为这一个按钮） |
| 🔄 订阅同步按钮 | 立即手动触发一次全自动订阅同步 |
| ■ 停止任务 | 停止当前下载/刷新任务 |
| 🌓 | 日夜主题切换 |

> **刷新列表 vs 抓取最新版本元数据**：这是两个概念。
> - **刷新列表**：只重读本地已保存的 `distributions.json` 到界面，**不联网**。用于后台任务完成后刷新展示。
> - **抓取最新版本元数据**：联网访问清华镜像站目录，把**最新版本**写进 `distributions.json`（默认每组保留最新 3 个），然后刷新列表。

## 镜像列表页

- **统计条**：发行版组数 / 清单文件数 / 本地已占空间 / 清单元数据更新时间。
- **筛选**：全部 / 已下载 / 未下载 / 已收藏。
- 每个发行版组可折叠/展开；每行有：
  - ★ 收藏
  - 🔒 锁定（受保护，清理/订阅同步不删）
  - 勾选框（选单个文件或整组）
  - 本地是否已下载标记
- 底部操作：勾选后「下载选中」「停止任务」等。
- 行内 ⬇：完整文件（后端判定 `downloadable`）可直接拉到本机，无需勾选。

## 种子下载页（v1.3.x）

三个子标签：**📚 种子源**（官方列表 / magnet / RSS 添加下载）、**⏳ 下载列表**（进度、全部/下载中/已完成/做种筛选、删除、勾选后拉到本机）、**🏷️ 分类管理**（自定义分类规则）。支持内置 qBittorrent sidecar 或外部 qB 实例。完整说明见 [种子下载](种子下载)。

## 自定义源页

添加清单里没有的发行版/任意 ISO 直链（如 Kali、特定 LTS、官方地址）。独立保存到 `custom_sources.json`，**不会被元数据刷新覆盖**。

支持两种条目：

- **普通直链**：发行版名 + ISO 直链，添加后立即合入镜像列表。
- **发行版源（strategy 目录抓取）**：`listing_url` + strategy，需先「🔄 刷新发行版源」展开为具体 ISO 条目。

页面操作：

- **🔄 刷新发行版源**（`POST /api/custom-sources/refresh`）：手动触发后台子进程重新展开所有 strategy 源并写缓存；请求线程只读缓存、不联网，故不会卡页面。
- **自动定时刷新开关**（`GET/POST /api/custom-sources/auto-refresh`）：可开启/关闭并设置间隔（秒）。**默认关闭**，间隔默认 `86400`（每天），最小 `60`。

> v1.1.6 起，strategy 发行版源的展开改为**持久化缓存 + 后台子进程**，请求线程内绝不发网络请求，从根上避免慢速抓站占满 waitress 线程导致全站卡死。详见 [自定义源](自定义源)。

## 订阅同步页

对每个发行版开启订阅：自动刷元数据 → 下载最新 N 版 → 删旧版。详见 [订阅同步](订阅同步)。

## 设置页

- **用户设置**：登录 / 修改管理员密码（PBKDF2-SHA256 加密）。
- **语言设置**：中文 / English / 自动（跟随系统）。
- **共享设置**：SMB / WebDAV 开关 + 凭据。
- **定时任务**：每天/每周/每月/每年/一次性，定时触发订阅同步。
- **受保护列表**：被 🔒 锁定的文件（清理/订阅同步跳过）。

## 任务进度与日志

- 顶部任务条显示：当前任务类型（下载/刷元数据）、标题、**进度条 + 百分比**、当前文件、已下载大小与速率。
- 下方日志面板实时滚动（下载每文件、校验、清理等事件）。

> 进度条卡在 0% / 日志只在停止后才刷出？见 [常见问题](常见问题-FAQ) 的「进度条卡 0%」条目——1.0.2 已修复根因。
