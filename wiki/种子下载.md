# 种子下载（qBittorrent / 下载到本机）

顶部导航「🧲 种子下载」页：用 qBittorrent 下载发行版官方种子 / magnet，下完后还能一键把文件拉回你自己的电脑。

> 功能演进：v1.3.17 补齐「已完成列表筛选 + 勾选下载到本机」；**v1.3.18** 子标签「下载中」更名「**下载列表**」、两个重名的「下载到本机」按钮**合并为一个**、并支持**外部 qBittorrent**（非 sidecar 部署）把种子文件下载回本机；**v1.3.19** 勾选行为对齐镜像列表——**发起下载后自动清空勾选**，且「种子源」页每行**新增勾选框支持批量添加下载**。

## 三个子标签

| 子标签 | 作用 |
|---|---|
| 📚 种子源 | 浏览 / 搜索可下载的种子条目，添加下载任务 |
| ⏳ 下载列表 | 查看下载 / 做种进度，筛选、删除、勾选后**下载到本机** |
| 🏷️ 分类管理 | 自定义种子分类规则（v1.3.13+） |

### 📚 种子源

- **官方种子列表**：内置 DistroWatch 等官方 RSS，开箱即用；「🔄 重新扫描源」手动刷新。
- **🔗 手动添加**：粘贴 `magnet:?xt=...` 或 `.torrent` 直链；可填「发行版名（可选）」决定落盘目录。
- **📡 RSS 源**：自行添加 `https://.../torrents.xml`。
- 条目带「本地已有」徽标 = 磁盘上已存在同名文件，避免重复下载。
- **批量下载（v1.3.19）**：每行左侧有勾选框，分类折叠头有半选态全选框（点全选框不会误触折叠）；顶部有「☑ 全选」。勾好后点顶部工具条（此时按钮自动变为「**⬇ 下载所选**」）即批量加入 qBittorrent。批量时**逐项提交**——每个种子按自己的标题推断发行版落盘目录，混选不同发行版也各自落对目录；完成后勾选自动清空并跳到「下载列表」。
- 落盘位置：能识别出发行版时存 `/data/<类型>/<发行版>/`，否则存 `/data/_torrents/`。

### 🏷️ 分类管理

- **预置分类**只能禁用、不能删除；「我的分类」可自由增删。
- 匹配规则：关键词按**词首**匹配（填 `ubuntu` 即覆盖 ubuntukylin 等派生版）；排除词按**完整词**匹配。
- 点「💾 保存分类设置」后，回到「种子源」页会自动重排（不重新抓外网）。

## ⏳ 下载列表

- 筛选 chips：**全部 / 下载中 / 已完成 / 做种**。
- 每行显示进度、速率、保存路径；可「删除种子」或「删种子 + 文件」（不可恢复）。
- 勾选若干行（含已完成 / 做种的），点顶部工具条「**⬇ 下载到本机**」，即可把这些种子里**已完成**的文件拉到打开面板的电脑。成功发起下载后勾选会**自动清空**（v1.3.19，与镜像列表行为一致）。
- 未连接 qB 时提示「未连接 qBittorrent(需部署 qbittorrent sidecar)」，见下节。

## 连接到 qBittorrent

两种形态任选其一：

1. **内置 sidecar（默认）**：compose 里启用 qbittorrent profile，iso-hub 经内部地址 `http://qbittorrent:8080` 连接，开箱即用。
2. **外部 qBittorrent**：在设置里填入你自己部署的 qB 地址（如 `http://192.168.1.5:8080`）与凭据。iso-hub 只调用它的 Web API 添加 / 列出种子，**不管理它的容器**。

## ⬇ 下载到本机（v1.3.14 起，v1.3.18 完善）

把**服务器上已下载完成**的文件（直链下载的 ISO 也行，不限于种子）拉回本地浏览器所在电脑：

- **一个按钮管两个面板**：顶部工具条「⬇ 下载到本机」会按当前面板自动切换——在「镜像列表」下载勾选的发行版文件，在「种子下载」下载勾选种子里已完成（进度 100% / 做种中）的文件。半成品（`.part` / `.aria2` / `.!qB` / `.tmp`）自动跳过，绝不会下发不完整字节。
- **大文件可续传**：分发用短时下载票据（默认 10 分钟、期内可复用），浏览器暂停 / 恢复不中断，票据里也不含长效会话凭据。
- **qB 已删种子的文件仍可下载**：只要文件还在服务器磁盘上（镜像列表里能看到就能拉回）。

### 外部 qB 下载回本机的挂载要求（v1.3.18，重要）

qBittorrent 的下载目录默认不在 iso-hub 的数据目录里。若 qB 写的是独立目录（典型如 `/downloads`），iso-hub 容器内**看不到**这些文件，勾选下载时会提示：

> N 个已完成文件不在 iso-hub 数据目录（外部 qB 需把下载目录按原路径挂载进容器）

解决：把**同一个宿主目录**按**同一路径**再挂载给 iso-hub 容器一份（只读即可）。例如 qB 容器已有挂载：

```yaml
# qbittorrent 容器(现有)
- /volume1/downloads:/downloads
```

则给 iso-hub 服务追加同样路径的挂载：

```yaml
# iso-hub 容器追加
services:
  iso-hub:
    volumes:
      - /volume1/downloads:/downloads:ro
```

两边路径必须一致（qB 报 `/downloads/动漫/xx.mp4`，iso-hub 容器里也要存在 `/downloads/动漫/xx.mp4`）。改完重建 iso-hub 容器生效。

> **安全说明**：数据目录外的文件走「绝对路径票据」，下载时服务端会**再次与 qB 当前报告的已完成文件逐字符核对**，客户端无法伪造路径读取服务器上的任意文件。未挂卷时提示会直接告诉你缺什么，而不是笼统报错「没有已完成的可下载文件」。

## 常见问题

- **点工具条「下载到本机」提示「请先勾选要下载的版本」**：当前停在「镜像列表」面板且没勾选任何行；切到「种子下载」勾选种子后再点即可（同一按钮按面板分发）。
- **点下载提示「没有已完成的可下载文件」**：勾选的种子还没下完（只下载进度 100% 或做种中的文件）。
- **外部 qB 明明下完了却拉不回来**：见上节挂载要求，把 qB 下载目录按原路径挂进 iso-hub 容器。
- **想删掉种子和它的文件**：下载列表行右侧「删种子+文件」，二次确认后不可恢复。
