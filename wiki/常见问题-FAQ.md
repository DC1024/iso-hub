# 常见问题（FAQ）

按实战遇到的真实问题整理，按频率排序。

## 1. 下载报错：`unrecognized arguments: "Arch", "download_url": ...`

**已修复（1.0.1+）**。这是旧版 bug：后端把命令拼成字符串后 `.split(" ")` 拆分，把带空格/逗号/引号的 JSON `--select` 参数拆坏成多个 argv，导致 argparse 报 unrecognized arguments。

- 现象：`iso_runner.py: error: unrecognized arguments: "Arch", "download_url": ...`
- 修复：命令以 **list** 传给 `subprocess.Popen`（不再字符串 split）。
- 解决：**升级到最新版本**（docker compose 重建）即可。

## 2. 日间模式，任务日志部分文字看不清（颜色接近背景）

**已修复（1.0.0+）**。原因：日志面板背景固定深色，但普通 `<pre>` 文本继承了日间主题的深色 `--ink`，深字配深底看不清；夜间主题 `--ink` 是浅色所以正常。

- 修复：日志区内文本改为固定浅色（`#cbe3ff` / `#d7e7ff` / 时间戳 `#8fb6dd`），不再依赖主题变量。
- 若仍看不清：强制刷新（Ctrl+F5）确保加载新前端（看标题徽章版本号）。

## 3. 下载没进度条

**已修复（1.0.1+）**。原因：后端 `/api/state` 的下载项缺少 `total` 字段，前端无法算百分比。

- 修复：下载前先 HEAD 探测目标文件大小（`#TARGET <path> <bytes>`），写入任务的 targets 映射，`running_task()` 据此给每项加 `total`，前端渲染进度条百分比。

## 4. 进度条卡在 0%，日志只在「停止任务」后才刷出

**已修复（1.0.2），本坑极隐蔽，务必升级。** 

根因不是后端，而是**前端变量遮蔽**：`poll()` 里 `const t = s.task` 用局部变量 `t` **遮蔽了全局 i18n 翻译函数 `t()`**。后续 `t('taskMeta')` / `t('curPrefix')` 抛 `TypeError: t is not a function`，被外层 try/catch 静默吞掉 → 任务类型/当前文件/进度条全不更新；`fetchLogs()` 也被跳过，所以日志只有走「停止任务」else 分支时才刷出。

- 修复：poll() 内局部变量 `t` 改名 `tk`；同时修了 `applySrcTpl()` 里同样的遮蔽。
- 升级到 **1.0.2+** 后，实机验证进度条正常 2%→4%→…持续增长。

## 5. 点「刷新列表」没反应，且分不清它和「抓取最新版本元数据」的区别

这是两个不同概念，都不是 bug：

- **刷新列表**：只**重读本地** `distributions.json` 到界面，**不联网**。用于后台任务完成后刷新展示。
- **抓取最新版本元数据**：**联网**访问清华镜像站，把**最新版本**写进清单（默认每组留最新 3 个）后再刷新列表。

若点「刷新列表」确实毫无反应：大概率是浏览器缓存了旧前端（徽章版本号偏旧）。**强制刷新**（Ctrl+F5）。

## 6. 顶部有两个「网络共享」，重复

**已修复（1.0.3）**。1.0.3 起删除顶部独立的「网络共享」标签页，网络共享统一并入**「设置 → 共享设置」**。功能一致（同一 `/api/shares` 后端）。

## 7. 网页能开，但下载/操作没权限提示

检查是否触发了登录/令牌门禁：

- `ISO_HUB_REQUIRE_LOGIN=1`（默认）：必须登录管理员账号。
- `ISO_HUB_TOKEN` 已设置：所有写操作还需弹窗输入令牌。

## 8. 8899 端口公网访问不了

- 确认容器在跑：`docker compose ps`
- 确认云厂商**安全组/防火墙**放行了对应端口（Lighthouse/腾讯云需在控制台放行，`lighthouse-ops` 可查）。
- 确认端口映射：`docker ps` 看 `0.0.0.0:8899->8080/tcp`。
- 用 `curl http://127.0.0.1:8899/api/health` 看容器内是否 ok。

## 9. 挂载 SMB 失败（网络/服务都正常）

服务端 SMB 正常、端口通、但客户端挂载失败时，九成是**客户端填法**：

- **不要**带 `smb://` 前缀（很多挂载向导不认，协议是单独选的）。
- **拆字段**：服务器IP 单独一栏、端口单独一栏、共享名 `iso` 单独一栏。
- 只能填整体串时：`<IP>:1445/iso`。
- 服务器端快速验证：`smbclient //<IP>/iso -p 1445 -U 'iso2%pass' -c 'ls'`。

详见 [网络共享](网络共享-SMB-WebDAV)。

## 10. 怎么确认我加载的是最新前端

看标题右上角**绿色徽章版本号**。对照 GitHub Releases 的最新 tag。小于最新说明是缓存，**Ctrl+F5 强制刷新**。
