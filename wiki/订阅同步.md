# 订阅同步（全自动拉新+删旧）

订阅同步让每个发行版**自动保持最新**：刷新元数据 → 下载最新 N 版 → 删除过期 ISO。

## 使用步骤

1. 进入「订阅同步」页，对某个发行版组点开启。
2. 设置**保留 N 个最新版本**（默认 2）。
3. 开启订阅。

## 触发方式

| 方式 | 说明 |
|---|---|
| 内置调度器 | 默认每天自动执行一次（`ISO_HUB_SYNC_INTERVAL`，秒；设 0 关闭） |
| 手动 | UI 右上角「🔄 订阅同步」立即触发一次 |
| cron | 任意时刻定时调接口 |

## cron 示例（每天凌晨 3 点全自动同步）

```bash
# 替换端口与令牌
0 3 * * * curl -s -X POST -H "X-Auth-Token: 你的令牌" http://127.0.0.1:8899/api/sync-subscriptions
```

## 自动执行的动作（对每个开启订阅的发行版）

1. 刷新该发行版元数据（抓最新版本）
2. 下载最新 N 版（缺哪个下哪个）
3. 删除组目录中**不在最新 N** 的过期 ISO

> 被 🔒 **锁定**（受保护）的文件在订阅同步/过期清理时**不会被删除**。

## 注意事项

- 订阅同步**不会覆盖** `custom_sources.json`（自定义源独立保存，但会并入候选池一起参与）。
- 若机器磁盘空间有限，谨慎设置保留数量，避免下载过多大镜像。
