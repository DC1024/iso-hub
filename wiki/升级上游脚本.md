# 升级上游脚本

ISO Hub 封装上游 [Sowevo/iso_download](https://github.com/Sowevo/iso_download)。上游更新（新发行版源、新解析逻辑）时可按下面升级。

## 步骤

```bash
# 在 iso-hub 目录内
rm -rf iso_download
git clone --depth 1 https://github.com/Sowevo/iso_download.git iso_download

# 国内无法直连 GitHub 时，可用加速镜像 zip:
#   ghfast.top / gh-proxy.com / ghproxy.net 前缀拼上 GitHub 下载地址

docker compose up -d --build
```

## 升级后注意

- **重建镜像**：`docker compose up -d --build`（不是只 `restart`）。
- `iso_download/` 是**只读上游脚本**，不要手改；本项目自己的逻辑在 `web/iso_runner.py`（选择性下载 runner）。
- 升级后建议点「抓取最新版本元数据」，让新版本源策略生效。
- 想调整"每组保留最新 N 个版本"：改 `iso_download/sources_config.json` 里各 source 的 `max_entries` 后重建。
