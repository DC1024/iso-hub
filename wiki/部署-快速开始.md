# 快速部署

ISO Hub 提供三种部署方式，任选其一：

| 方式 | 适合场景 | 共享 sidecar |
|---|---|---|
| **1.2 阿里云源** | **国内服务器（推荐）**：拉取快、公开仓库无需登录 | ✅ iso-hub 走阿里云，samba/webdav 走 Docker Hub |
| 1.1 Docker Hub 源 | 海外服务器 | ✅ 三容器均从 Docker Hub 拉取 |
| 2. 源码构建 | 需要改代码 / 自定义网络共享镜像 | ✅ 三容器本地构建 |

## 前置要求

- 一台 Linux 服务器（或 NAS），已装 **Docker** + **Docker Compose**。
- 至少 2 核 / 2G 内存 / 足够放 ISO 的磁盘（一个发行版镜像通常 1–10GB）。
- 国内服务器建议配好 Docker 镜像加速（见下文）。

---

## 1. 使用 Docker 部署

直接拉取现成镜像，**无需本地构建**。以下两种镜像源内容相同，按网络情况任选其一。

### 1.1 Docker Hub 源部署方式

镜像由 GitHub Actions 在每次 push 到 `master` 时自动构建并推送。

**docker run 方式：**

```bash
docker pull dcchendockeruser/iso-hub:latest

docker run -d --name iso-hub \
  -p 8899:8080 \
  -v "$PWD/data:/data" \
  -e TZ=Asia/Shanghai \
  dcchendockeruser/iso-hub:latest
```

**docker compose 方式**（含 SMB/WebDAV 共享，三个容器）：

保存为 `docker-compose.yml`：

```yaml
services:
  iso-hub:
    image: dcchendockeruser/iso-hub:latest    # Docker Hub 源
    container_name: iso-hub
    restart: unless-stopped
    ports:
      - "${ISO_HUB_PORT:-8899}:8080"
    volumes:
      - ./data:/data
      - /var/run/docker.sock:/var/run/docker.sock
    environment:
      - TZ=Asia/Shanghai
      - ISO_HUB_TOKEN=${ISO_HUB_TOKEN:-}
      - ISO_HUB_REQUIRE_LOGIN=${ISO_HUB_REQUIRE_LOGIN:-1}
      - ISO_HUB_SYNC_INTERVAL=${ISO_HUB_SYNC_INTERVAL:-86400}
    healthcheck:
      test: ["CMD", "python", "-c", "import urllib.request as u;u.urlopen('http://127.0.0.1:8080/api/health',timeout=4)"]
      interval: 60s
      timeout: 5s
      retries: 3
      start_period: 15s

  samba:
    image: dperson/samba:latest
    container_name: iso-hub-samba
    restart: unless-stopped
    ports:
      - "${SAMBA_PORT:-1445}:445"
      - "${SAMBA_NETBIOS:-1137}:137/udp"
      - "${SAMBA_138:-1138}:138/udp"
      - "${SAMBA_139:-1139}:139"
    volumes:
      - ./data:/srv/iso:ro
    environment:
      - TZ=Asia/Shanghai
      - USERID=${SAMBA_UID:-0}
      - GROUPID=${SAMBA_GID:-0}
    command: >-
      -p
      -u "${SAMBA_USER:-iso};${SAMBA_PASS:-iso123}"
      -s "iso;/srv/iso;no;no;no;${SAMBA_USER:-iso},${SAMBA_PASS:-iso123}"

  webdav:
    image: hacdias/webdav:latest
    container_name: iso-hub-webdav
    restart: unless-stopped
    ports:
      - "${WEBDAV_PORT:-8081}:6065"
    volumes:
      - ./data:/data:ro
      - ./data/webdav.yml:/config.yml:ro
    environment:
      - TZ=Asia/Shanghai
    command: ["-c", "/config.yml"]
```

启动：

```bash
mkdir -p /opt/iso-hub/data && cd /opt/iso-hub
docker compose pull
docker compose up -d
```

打开 `http://<服务器IP>:8899` 即可。SMB `smb://<IP>:1445/iso`，WebDAV `http://<IP>:8081/dav`（账号 `iso` / 密码 `iso123`）。

### 1.2 阿里云 ACR 源部署方式（国内推荐）

国内服务器从 Docker Hub 拉取经常超时或失败，因此镜像同时推送到 **阿里云容器镜像服务（华东1·杭州）**。该仓库已设为**公开**，**无需 `docker login`** 即可直接拉取，国内速度明显更快。

| 项目 | 值 |
|---|---|
| 镜像地址 | `registry.cn-hangzhou.aliyuncs.com/dcchen/isohub` |
| 可用标签 | `latest`（push master 时构建）；`1.0.6` 这类版本号（打 `v1.0.6` tag 时构建） |
| 构建方式 | GitHub Actions（workflow：`.github/workflows/aliyun-acr.yml`）自动构建推送 |

**docker compose 方式（推荐，含 SMB/WebDAV 共享，三个容器）：**

把下面内容保存为 `docker-compose.yml`（iso-hub 主镜像走阿里云，samba/webdav 走 Docker Hub）：

```yaml
services:
  iso-hub:
    image: registry.cn-hangzhou.aliyuncs.com/dcchen/isohub:latest   # 国内阿里源, 无需 docker login
    container_name: iso-hub
    restart: unless-stopped
    ports:
      - "${ISO_HUB_PORT:-8899}:8080"
    volumes:
      - ./data:/data
      - /var/run/docker.sock:/var/run/docker.sock
    environment:
      - TZ=Asia/Shanghai
      - ISO_HUB_TOKEN=${ISO_HUB_TOKEN:-}
      - ISO_HUB_REQUIRE_LOGIN=${ISO_HUB_REQUIRE_LOGIN:-1}
      - ISO_HUB_SYNC_INTERVAL=${ISO_HUB_SYNC_INTERVAL:-86400}
    healthcheck:
      test: ["CMD", "python", "-c", "import urllib.request as u;u.urlopen('http://127.0.0.1:8080/api/health',timeout=4)"]
      interval: 60s
      timeout: 5s
      retries: 3
      start_period: 15s

  samba:
    image: dperson/samba:latest
    container_name: iso-hub-samba
    restart: unless-stopped
    ports:
      - "${SAMBA_PORT:-1445}:445"
      - "${SAMBA_NETBIOS:-1137}:137/udp"
      - "${SAMBA_138:-1138}:138/udp"
      - "${SAMBA_139:-1139}:139"
    volumes:
      - ./data:/srv/iso:ro
    environment:
      - TZ=Asia/Shanghai
      - USERID=${SAMBA_UID:-0}
      - GROUPID=${SAMBA_GID:-0}
    command: >-
      -p
      -u "${SAMBA_USER:-iso};${SAMBA_PASS:-iso123}"
      -s "iso;/srv/iso;no;no;no;${SAMBA_USER:-iso},${SAMBA_PASS:-iso123}"

  webdav:
    image: hacdias/webdav:latest
    container_name: iso-hub-webdav
    restart: unless-stopped
    ports:
      - "${WEBDAV_PORT:-8081}:6065"
    volumes:
      - ./data:/data:ro
      - ./data/webdav.yml:/config.yml:ro
    environment:
      - TZ=Asia/Shanghai
    command: ["-c", "/config.yml"]
```

启动：

```bash
mkdir -p /opt/iso-hub/data && cd /opt/iso-hub
docker compose pull          # 从阿里云拉取 iso-hub, 从 Docker Hub 拉取 samba/webdav
docker compose up -d
```

**docker run 方式：**

```bash
docker pull registry.cn-hangzhou.aliyuncs.com/dcchen/isohub:latest
docker run -d --name iso-hub \
  -p 8899:8080 \
  -v "$PWD/data:/data" \
  -e TZ=Asia/Shanghai \
  registry.cn-hangzhou.aliyuncs.com/dcchen/isohub:latest
```

**升级：**

```bash
cd /opt/iso-hub
docker compose pull && docker compose up -d
```

> 注意：`samba` / `webdav` 两个镜像来自 Docker Hub（`dperson/samba`、`hacdias/webdav`），国内拉取可能较慢；只有 iso-hub 主镜像走阿里云。若这两个也拉不动，可改用 [方式 2 源码构建](#2-使用源码构建部署含-smbwebdav-共享) 或给 sidecar 配 Docker Hub 加速。
> 仓库内另附 `docker-compose.acr.yml`，与本示例等价，可直接 `docker compose -f docker-compose.acr.yml up -d`。

## 2. 使用源码构建部署（含 SMB/WebDAV 共享）

需要网络共享（SMB/WebDAV）或想改代码时用这种方式，会构建 iso-hub 主服务 + samba + webdav **三个容器**。

```bash
git clone https://github.com/DC1024/iso-hub.git
cd iso-hub

# 可选：设置访问令牌（公网强烈建议）
# echo "ISO_HUB_TOKEN=你的随机密码" > .env

docker compose up -d --build
```

打开 `http://<服务器IP>:8899` 即可。

## 国内服务器镜像加速

源码构建时 `pip install` 依赖可指定国内 PyPI 源加速（在 `docker-compose.yml` 同级 `.env` 写）：

```ini
PIP_INDEX_URL=https://mirrors.aliyun.com/pypi/simple/
```

拉镜像若有困难，可在 Docker daemon 配置 registry-mirrors（如 docker.1panel.live / docker.m.daocloud.io 等，视可用性而定）。

## 首次启动必做

1. **登录**：首次打开会要求设置/输入管理员密码（单管理员账号，PBKDF2 加密存储）。
2. **抓取最新元数据**：点右上角「抓取最新版本元数据」，把内置样例清单刷新为当前镜像站上的最新版本。
3. **下载**：勾选发行版/版本，点「下载」。

## 常用命令

```bash
docker compose logs -f iso-hub      # 看主服务日志
docker compose restart iso-hub      # 重启主服务
docker compose ps                   # 看三个容器状态
docker exec iso-hub python /app/iso_download/update_distributions.py \
  --output /data/distributions.json --pretty   # 手动刷一次元数据
```

## 常见部署失败

| 现象 | 处理 |
|---|---|
| 构建时 pip 超时 | 配 `PIP_INDEX_URL` 为国内源 |
| 8899 访问不了 | 检查云厂商安全组/防火墙是否放行该端口 |
| 页面能开但下载就报错 | 看「常见问题」的下载报错条目 |
