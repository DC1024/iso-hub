# 快速部署（Docker Compose）

## 前置要求

- 一台 Linux 服务器（或 NAS），已装 **Docker** + **Docker Compose**。
- 至少 2 核 / 2G 内存 / 足够放 ISO 的磁盘（一个发行版镜像通常 1–10GB）。
- 国内服务器建议配好 Docker 镜像加速（见下文）。

## 方式一：源码 docker compose（推荐，功能最全）

含主服务 + SMB 共享 + WebDAV 共享三个容器。

```bash
git clone https://github.com/DC1024/iso-hub.git
cd iso-hub

# 可选：设置访问令牌（公网强烈建议）
# echo "ISO_HUB_TOKEN=你的随机密码" > .env

docker compose up -d --build
```

打开 `http://<服务器IP>:8899` 即可。

## 方式二：直接拉 Docker Hub 镜像（单容器，无共享）

```bash
docker pull dcchendockeruser/iso-hub:latest
docker run -d --name iso-hub \
  -p 8899:8080 \
  -v "$PWD/data:/data" \
  dcchendockeruser/iso-hub:latest
```

> 镜像由 GitHub Actions 在每次 push 到 `master` 时自动构建推送。**不含** SMB/WebDAV 共享容器；要共享请用方式一。

## 国内服务器镜像加速

构建时会 `pip install` 依赖，可指定国内 PyPI 源加速（在 `docker-compose.yml` 同级 `.env` 写）：

```ini
PIP_INDEX_URL=https://mirrors.aliyun.com/pypi/simple/
```

拉镜像若有困难，可在 Docker daemon 配置 registry-mirrors（如 docker.1panel.live / docker.m.daocloud.io 等，视可用性而定）。

## 首次启动必做

1. **登录**：首次打开会要求设置/输入管理员密码（单管理员账号，PBKDF2 加密存储）。
2. **抓取最新元数据**：点右上角「抓取最新版本元数据」，把内置样例清单刷新为当前镜像站上的最新版本。
3. **下载**：勾选发行版/版本，点「下载」。

## 常用命令

```bash
docker compose logs -f iso-hub      # 看主服务日志
docker compose restart iso-hub      # 重启主服务
docker compose ps                   # 看三个容器状态
docker exec iso-hub python /app/iso_download/update_distributions.py \
  --output /data/distributions.json --pretty   # 手动刷一次元数据
```

## 常见部署失败

| 现象 | 处理 |
|---|---|
| 构建时 pip 超时 | 配 `PIP_INDEX_URL` 为国内源 |
| 8899 访问不了 | 检查云厂商安全组/防火墙是否放行该端口 |
| 页面能开但下载就报错 | 看「常见问题」的下载报错条目 |
